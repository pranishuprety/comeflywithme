# comeflywithme

The sky is yours.

A lightweight, browser-based 3D flight simulator built with TypeScript, Three.js, and Vite.

## Play

```bash
npm install
npm run dev
```

Open the local URL Vite prints, then click **Play**.

## Controls

| Input | Action |
|-------|--------|
| Mouse | Pitch & roll (click canvas to capture) |
| Arrow keys | Pitch & roll |
| Q / E | Rudder |
| W / S | Throttle |
| G | Landing gear |
| Space | Wheel brakes |
| C | Cycle camera |
| P | Pause |
| R | Restart |
| Esc | Return to menu |

## Aircraft

- **Skyhopper** — forgiving light trainer
- **Twin Hauler** — heavy STOL turboprop
- **Viper** — fast, high-stall fighter

## Modes

- **Free Flight** — explore a procedural world
- **Landing Challenge** — approach and land at East Bay
- **Checkpoints** — fly a gate course

## Stack

TypeScript · Three.js · Vite · Web Audio (procedural) · plain CSS
